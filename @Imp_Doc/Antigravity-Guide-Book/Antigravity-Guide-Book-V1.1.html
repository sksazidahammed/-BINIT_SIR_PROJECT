0 · Read this first

Honest scope: what this book is and isn't

No tool makes Antigravity "a million times better". Real gains come from stacking five things: clear rules, reusable skills, the right MCP connections, a plan-first workflow, and security checks. This book gives you each, in order.

3 · The customization layers

This is where most of the quality gain comes from

LayerWhat it doesWhere it lives
RulesPersistent system-style instructions (coding standards, stack, "never do X")Global ~/.gemini/GEMINI.md · Workspace .agents/rules/ (older guides say .agent/rules/)
WorkflowsSaved step sequences you trigger on demand (deploy, PR reply, test cycle).agents/workflows/ · global ~/.gemini/antigravity/global_workflows/
SkillsSKILL.md folders; the agent sees only name and description until a skill is needed.agents/skills/<name>/SKILL.md
agents.mdDefines a named custom agent with its own model, permissions and MCP access; newer IDEs also read AGENTS.mdProject root / .agents/
MCPConnects the agent to databases, browsers, GitHub, Firebase and moreAgent panel → MCP Servers → View raw config (mcp_config.json)

Each Rules or Workflows file is reportedly capped at about 12,000 characters, so split long style guides. Folder names have changed between versions: confirm in the official docs for yours. Sources: Prompt Shelf guide, Substack guide.

# Starter workspace rule (.agents/rules/stack.md)
- Stack: TypeScript, React, Tailwind. Small components in /src/components.
- Plan first: write a plan and wait for my approval on anything over 3 files.
- Write tests for every new function. Never commit secrets; use .env.
- Never run destructive commands (rm -rf, DROP, force-push) without asking.

6 · Plan-first workflow (the 8-step loop)

Use for every feature

Idea→Spec→Plan (approve)→Build→Test→Review→Security→Ship
Prompt template:
"Interview me about this feature. Then write SPEC.md (goals, non-goals,
acceptance tests). Wait for approval. Then write PLAN.md with small
steps. Build one step at a time and run tests after each."

Tools for this stage: GSD, Superpowers (section 4) and your spec-driven planning catalogue. Your own saved docs also cover this: Antigravity AI Development System unchecked, Idea → Live App Workflow unchecked, Architecture Stress-Test Prompt Pack unchecked.

8 · Design & frontend quality

Avoid generic "AI slop" UI

  • Install UI/UX Pro Max, then ask the agent to generate a design system (colors, type, spacing) before building screens.
  • Use browser MCP to screenshot, then comment directly on the screenshot to steer the agent.

Too many skills

Noise lowers accuracy. Curate.

Giant rules files

Past the size cap, parts are ignored.

Blind trust

Test and review everything it writes.
